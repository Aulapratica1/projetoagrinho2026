# projetoagrinho2026
O site da EcoGen Desenvolvimentos é uma plataforma técnica e interativa projetada para simular o impacto sustentável do uso de sementes geneticamente melhoradas na agricultura. Suas principais funcionalidades são:

Calculadora Agronômica em Tempo Real: Calcula o consumo volumétrico total de água (em litros) e a necessidade de irrigação líquida (em milímetros) com base no tamanho da lavoura informado pelo usuário.

Simulador de Modificadores Genéticos: Permite aplicar melhorias laboratoriais adicionais (como otimização de estômatos e aprofundamento radicular) para reduzir ainda mais a demanda hídrica da cultura selecionada.

Gerenciamento Completo de Sementes (CRUD): Interface profissional para cadastrar novas culturas, listar as sementes salvas, editar dados técnicos existentes e excluir registros do banco de dados.

Painel Independente de Edição: Um módulo visual dedicado que é acionado apenas quando o usuário deseja alterar os dados de uma cultura, organizando o fluxo de trabalho.

Indexador de Sementes (Busca Simulada): Campo de pesquisa que simula uma varredura na web para encontrar dados de evapotranspiração de culturas específicas e preencher o formulário automaticamente.

Sistema de Notificações Integrado (Toasts): Alertas visuais fluidos na tela que informam instantaneamente o sucesso ou falha de cada comando executado pelo usuário.
